# Shekina Birthday Surprise 🌌💜

## Files
- index.html
- style.css
- script.js

## Run it
Double-click `index.html` or open it with a browser.

## Add photos
Create an `images` folder and put your photos there. Then replace the photo placeholder in `index.html` with an `<img>` element.

## Add music
Create an `audio` folder, put a song you are allowed to use inside it, then edit `script.js`:
`const MUSIC_FILE = "audio/birthday-song.mp3";`

## Publish it
Upload these files to GitHub Pages, Netlify, Vercel, or another static host. No Firebase or database is required.
